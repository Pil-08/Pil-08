# Samuel Pil

Estudio Informática en la UPV y vivo en Donostia. Fuera de clase hago webs a mano para bares,
cafeterías y restaurantes de la ciudad, con HTML, CSS y JavaScript y sin frameworks. Me
interesa que cada una sea un trabajo entero: la carta bien puesta, varios idiomas y nada que
se rompa con el tiempo por depender de una librería.

## Lo que hay por aquí

**[Oasis Kafe](https://github.com/Pil-08/Oasis-Kafe)** — cafetería y pastelería de Antiguo. Toda
la web cabe en un único fichero HTML: la carta, el horario y un carrito que prepara el pedido
para mandarlo por WhatsApp, en cuatro idiomas. [Verla](https://oasis-kafe-web.pages.dev)

**[Buga Ramen](https://github.com/Pil-08/Buga-Ramen)** — un restaurante de ramen e izakaya. Carta
completa también como datos estructurados para los buscadores, tipografías propias e imágenes en
AVIF y WebP, en tres idiomas. [Verla](https://bugaramensansebastian.pages.dev)

**[Onigiri Edorin](https://github.com/Pil-08/Onigiri-Edorin)** — un local de comida japonesa y
coreana, con imágenes en AVIF y WebP, tipografías propias y respeto al «reducir movimiento», en
tres idiomas. [Verla](https://onigiri-edorin.pages.dev)

**[LA COMMANDE](https://github.com/Pil-08/LA-COMMANDE)** — la web con la que ofrezco este trabajo
a negocios de hostelería de Donostia. [Verla](https://la-commande.pages.dev)

**[Sistema de facturación de un supermercado](https://github.com/Pil-08/Java-OOP-Sistema-Facturacion-Supermercado)**
— una práctica de Java orientado a objetos: clase abstracta, herencia, polimorfismo y
enumerados.
